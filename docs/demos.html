<pdf-viewer>

Home Demos API

Basic Usage

A simple viewer with default settings. Just set the src attribute.

<pdf-viewer src="sample.pdf" style="height: 500px"></pdf-viewer>

With Thumbnails

Add show-thumbnails to display a sidebar with page previews.

<pdf-viewer src="sample.pdf" show-thumbnails style="height: 500px"></pdf-viewer>

Continuous Scroll

Set view="continuous" to scroll through all pages.

<pdf-viewer src="sample.pdf" view="continuous" style="height: 500px"></pdf-viewer>

Dark Mode

Set mode="dark" or let it auto-detect from the page theme.

<pdf-viewer src="sample.pdf" mode="dark" style="height: 500px"></pdf-viewer>

Restricted Controls

Use no-download and no-print to hide those buttons.

<pdf-viewer src="sample.pdf" no-download no-print style="height: 500px"></pdf-viewer>

Custom Zoom

Set an initial zoom level with the zoom attribute.

<pdf-viewer src="sample.pdf" zoom="1.5" style="height: 500px"></pdf-viewer>

Specific Page + Title

Jump to a specific page on load and display a title in the toolbar.

<pdf-viewer src="sample.pdf" page="3" title="Zoom Controls" style="height: 500px"></pdf-viewer>

External Document

A real-world PDF loaded into the viewer with thumbnails enabled.

<pdf-viewer src="sample2.pdf" show-thumbnails title="Sample 2" style="height: 600px"></pdf-viewer>

No Toolbar

Hide the toolbar entirely with show-toolbar="false".

<pdf-viewer src="sample.pdf" show-toolbar="false" style="height: 400px"></pdf-viewer>

Browse & View

Pick a PDF from your computer to view it right here. You can also drag and drop onto the viewer.

<button onclick="document.querySelector('pdf-viewer').openFile()">
  Browse for PDF...
</button>
<pdf-viewer id="viewer" style="height: 600px"></pdf-viewer>

<script>
  const viewer = document.getElementById('viewer')
  viewer.addEventListener('file-opened', (e) => {
    console.log('Opened:', e.detail.name, e.detail.size, 'bytes')
  })
  viewer.addEventListener('pdf-loaded', (e) => {
    console.log('Loaded:', e.detail.pageCount, 'pages')
  })
</script>

Programmatic Loading

Load PDFs via JavaScript using setData() or openFile().

const viewer = document.querySelector('pdf-viewer')

// From fetch
const response = await fetch('document.pdf')
const buffer = await response.arrayBuffer()
await viewer.setData(buffer)

// From file picker
viewer.openFile()

Event Handling

const viewer = document.querySelector('pdf-viewer')

viewer.addEventListener('pdf-loaded', (e) => {
  console.log('Loaded:', e.detail.pageCount, 'pages')
})

viewer.addEventListener('page-change', (e) => {
  console.log('Page:', e.detail.page, 'of', e.detail.pageCount)
})

viewer.addEventListener('zoom-change', (e) => {
  console.log('Zoom:', e.detail.zoom)
})
