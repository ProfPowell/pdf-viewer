<pdf-viewer>

A standalone web component for viewing PDF documents. Built on PDF.js with navigation, zoom, search, thumbnails, and full theme support.

Features

PDF.js Powered

High-fidelity PDF rendering via Mozilla's PDF.js library

Navigation

Page-by-page or continuous scroll with keyboard shortcuts

Zoom Controls

Fit-width, fit-page, manual zoom, and pinch-to-zoom

Text Search

Full-text search with match highlighting and navigation

Thumbnails

Sidebar with lazy-rendered page thumbnails

Dark Mode

Auto-detects page theme or set explicitly via attribute

File Input

Drag-and-drop, file picker, or programmatic loading

Framework Agnostic

Works with any framework or vanilla HTML

Live Demo

Quick Start

Install

npm install @profpowell/pdf-viewer

Usage

<script type="module">
  import '@profpowell/pdf-viewer'
</script>

<pdf-viewer src="document.pdf"></pdf-viewer>

With options

<pdf-viewer
  src="report.pdf"
  page="1"
  zoom="fit-width"
  show-thumbnails
  title="Annual Report"
  style="height: 600px"
></pdf-viewer>
